## What you can't do without asking

- Use the Empire Engine name or crown logo as the name or logo of your own engine, editor, fork or product, or in a way that

- Publish a modified Empire Engine under a name that is Empire Engine, or one so close it could be mistaken for it.

If you make and release a fork, give it its own name and replace the logo files listed above (and the window icons,
which come from them). The code builds and runs the same without them.

The BRUTAL logo in `Engine.Brutal/Ui/Logos/BrutalLogo.png` belongs to Ahwoo Limited. It is shown on the splash screen
because the [BRUTAL License](Licenses/BRUTAL-LICENSE.txt) requires every product built with BRUTAL to show it before
gameplay, unaltered except for scaling, and no less prominently than other logos. **A fork must keep it** unless Ahwoo Limited
has given written permission otherwise.
