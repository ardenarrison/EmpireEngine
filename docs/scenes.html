Using the editor

Scenes and objects

A scene is a tree of objects. Each object has a position, a rotation and a scale, and a list of components that give it its looks and behaviour.

Objects

Every object in a scene (a SceneObject) has:

PropertyMeaning
IdA GUID that never changes. Scene files, undo and object fields in scripts refer to objects by it.
NameWhat the Hierarchy shows, and what Scene.FindObjectWithName searches for. Names don't have to be unique.
Position, Rotation, ScaleThe transform, relative to the parent (or to the world for a top-level object). Rotation is a Quaternion; the Inspector shows it as degrees.
Parent, ChildrenWhere it sits in the tree. Change these through the editor, or Scene.SetParent from code.
ComponentsIts components, in the order they were added.
WorldMatrixThe object's transform in the world, with all its parents applied. WorldMatrix.Translation is its world position.
SceneNameWhich loaded scene it came from, when several are loaded. See Loading scenes.

Units and axes

  • One unit is one meter. Physics, gravity (9.81 down) and sound distances all assume this.
  • Y is up. Cameras and spot lights look along their local −Z axis, as in glTF.
  • Rotations in script helpers such as Rotate(x, y, z) are in degrees. Raw Quaternion math uses radians.

Components

A component is a piece of data or behaviour on an object. The engine's own components are listed in the Component reference:

  • Looks: Mesh, Camera, Directional / Point / Spot Light, Environment, Particle System, Terrain
  • Movement: Rigidbody, Box / Sphere / Mesh Collider, Animator, Spin
  • Sound: Audio Source, Audio Listener
  • Interface: UI elements (Button, Text Field, Checkbox, Dropdown, Bar)
  • Code: Script, which attaches a Behaviour or a custom component

Some components can only appear once per object: Environment, Rigidbody, Terrain, Animator and Audio Listener. Add Component leaves them out when the object already has one.

Scene settings

A few settings belong to the whole scene. Click the scene file in the Assets panel and they appear in the Inspector. This works for scenes other than the open one too; their file is updated as soon as an edit settles.

SettingDefaultMeaning
ShadowsonOff turns shadows off for the whole scene, whatever the sun says.
Shadow Resolution2048Size of the sun's shadow map: 512, 1024, 2048 or 4096. Bigger is sharper and costs more GPU memory (4096 uses 64 MB for each of the two frames in flight).
Gravity(0, −9.81, 0)The pull on rigidbodies that use gravity. Reset Gravity puts it back. Scripts can change it with Physics.Gravity.

Making scenes

Right-click anywhere in the Assets panel and choose Create Scene. The new .empirescene file goes in the folder being shown. Scenes in Scenes/ are loaded from scripts by name (SceneManager.LoadScene("Level2")); scenes elsewhere are loaded by their path from the project folder.

Finding objects from a script

var player = Scene.FindObjectWithName("Player");          // first match, or null
List<SceneObject> coins = Scene.FindObjectsWithName("Coin");  // every match

// The scene that's playing, for anything else:
foreach (var obj in SceneManager.World!.All) { ... }

Names are matched exactly, capital letters included, in Hierarchy order. Searching takes time in a big scene, so find what you need once in Start and keep it. For objects you know in advance, an object field dragged in from the Hierarchy is better still.

Scene files

Scenes are saved as readable JSON (.empirescene), so they diff well in version control. See File formats for the layout.
