File formats

Every file Empire Engine writes is JSON, so it reads well in a diff and survives version control. These are their layouts.

FileWhereWhat
project.empireproject rootThe project's name, editor version and start scene
*.empiresceneScenes/ (usually)A scene
*.visualcodeScripts/A visual script
packages.jsonPackages/The packages a project has turned on
package.jsoneach package's folderA package's id, name, version and description
game.jsona built game's GameData/The game's name and start scene
*.empiresavethe saves folderOne save-game slot

project.empire

{
  "name": "My Game",
  "editorVersion": "0.1.0",
  "startScene": "Scenes/Main.empirescene"
}

startScene defaults to Scenes/Main.empirescene. The Hub writes this file; a folder without one still opens if it has a scene in Scenes/.

Scene files (.empirescene)

{
  "formatVersion": 1,
  "name": "Main",
  "settings": {
    "shadows": true,
    "shadowResolution": 4096,
    "gravity": [0, -9.81, 0]
  },
  "objects": [
    {
      "id": "a1b2c3d4-0000-4000-8000-00000000000f",
      "name": "Sun",
      "position": [0, 10, 0],
      "rotation": [0, 0, 0, 1],
      "scale": [1, 1, 1],
      "components": [
        { "type": "DirectionalLight", "intensity": 4, "lightColor": [1, 0.96, 0.88], "yaw": 33.69, "pitch": 47.96 }
      ]
    },
    {
      "id": "60307893-9d17-4e0a-9ce7-b39f1c5a24fd",
      "name": "Water",
      "position": [0, 1.5, 0],
      "rotation": [0, 0, 0, 1],
      "scale": [100, 1, 100],
      "components": [
        { "type": "MeshRenderer", "model": "Models/Sea.glb", "tint": [1, 1, 1, 1] },
        { "type": "Script", "scriptName": "Water", "fields": { "Smoothness": "0.8" } }
      ]
    }
  ]
}
  • Vectors are arrays. rotation is a quaternion as [x, y, z, w].
  • Objects are listed parents first. A child names its parent's id in parent; top-level objects have no parent key (empty values aren't written). A parent must appear before its children, or loading fails with a clear message.
  • Each component has a type: MeshRenderer, Script, Camera, DirectionalLight, PointLight, SpotLight, Environment, Rigidbody, BoxCollider, SphereCollider, MeshCollider, Terrain, Animator, ParticleSystem, AudioSource, AudioListener, Ui or Spin.
  • A Script component's fields holds only values changed in the Inspector, each as JSON text ("5", "\"hi\"", "[1,2]"). Object fields hold the target's id.
  • Terrain heights and paint are stored compressed (deflate, then base64), so large terrains stay compact.
  • Scenes saved before scene settings existed have no settings and get the defaults.

Visual scripts (.visualcode)

{
  "version": 1,
  "name": "Spinner",
  "variables": [
    { "name": "speed", "type": "number", "default": "1" }
  ],
  "nodes": [
    { "id": "n1", "type": "when_start", "x": 40, "y": 40, "next": "n2" },
    { "id": "n2", "type": "go_to", "x": 0, "y": 0, "next": "n3",
      "inputs": { "x": { "literal": "0" }, "y": { "literal": "0" }, "z": { "literal": "0" } } },
    { "id": "n3", "type": "forever", "x": 0, "y": 0, "body": "n4" },
    { "id": "n4", "type": "turn", "x": 0, "y": 0,
      "inputs": { "axis": { "literal": "Y" }, "degrees": { "literal": "2" } } }
  ]
}

Each node is a block. next is the block below it, body the first block inside a C-block's mouth, and each input is either a literal value or a node (a plugged-in reporter). Saving writes the matching .cs next to it.

packages.json

{
  "enabled": [ "Water" ]
}

The ids of the installed packages, in the order they were turned on. Each has a compiled EmpirePackage.<Id>.dll and a .stamp beside it.

package.json

{
  "id": "Water",
  "name": "Water",
  "version": "1.5.0",
  "description": "Adds a Water component..."
}

id (letters, digits, underscores) defaults to the folder's name, name to the id, and version to 1.0.0.

game.json

{
  "name": "My Game",
  "startScene": "Scenes/Main.empirescene"
}

Written by Build Project. startScene is relative to GameData/Core/.

Save games (.empiresave)

One file per slot with the format version, when it was saved, the active and loaded scenes, Time.time, your SetInt/SetString values, and the whole world in the same form as a scene file (plus runtime state such as velocities and audio positions).
