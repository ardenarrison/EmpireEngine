Terrain

Ground made from a grid of heights, for hills, valleys and plains. Sculpt it with brushes, paint it with colors, or generate hills, and it works as a collider straight away.

Adding terrain

Right-click in the Hierarchy and choose Terrain. You get a 60 × 60 terrain at the scene's origin with gentle generated hills and three paint layers ready to use: Dirt, Sand and Stone. You can also add a Terrain component to any object (one per object).

Size and shape

The terrain is centered on its object. It spans Width along X and Length along Z, and rises from the object's position up to Height.

SettingDefaultMeaning
Width, Length60, 60Size in the object's local units
Height12The highest the ground can rise above the object
Resolution129 × 129Grid points per side: 33, 65, 129, 257 or 513. More holds finer detail and costs more to draw. Changing it resamples the ground, keeping its shape.
Base ColorgreenThe color of ground with no paint on it
CollideonOff makes it scenery only: nothing collides with it and raycasts pass through
Friction, Bounciness0.5, 0As for any collider

Sculpting

Press Sculpt Terrain in the Inspector. While it's on, hold the left mouse button over the terrain to use the brush; a ring shows its size. Right-drag and WASD still fly the camera. Press the button again to stop.

BrushDoes
RaiseLifts the ground under the brush
LowerDigs it down
SmoothEvens out bumps
FlattenPulls the ground toward the Flatten To height
PaintPaints the chosen layer's color
EraseRemoves paint, back to the base color

Brush Size is the radius and Strength how fast it works. Each stroke is one undo step.

Paint layers

A layer is a named color, such as "Road" or "Snow", that you paint onto specific spots. A terrain can have up to 8 layers. Pick one in the list to paint with it; rename it, change its color (paint already on the ground follows), or remove it (what was painted goes back to the base color). Fill With Selected paints the whole terrain; Clear Paint removes all paint.

Generating hills

The Generate section fills the terrain with hills made from layered noise. The same settings always give the same hills.

SettingMeaning
SeedA different number gives a different landscape. Random Seed picks one.
Hill SizeWidth of the biggest hills, in local units
DetailHow many layers of finer bumps go on top (1 to 8)
RoughnessHow strong that finer detail is, 0 to 1
AmountHow much of Height the hills use, 0 to 1

Generate Hills, Flatten All and Smooth All replace the whole ground; Cmd/Ctrl+Z brings it back.

From scripts

public class StickToGround : Behaviour
{
    public SceneObject? ground;      // drag the terrain object here
    private Terrain? _terrain;

    public override void Start() => _terrain = ground?.Components.OfType<Terrain>().FirstOrDefault();

    public override void Update()
    {
        if (_terrain == null || ground == null) return;
        var p = Object.Position;
        Object.Position = new Vector3(p.X, _terrain.GetHeight(ground, p), p.Z);
    }
}
MemberDoes
GetHeight(owner, worldPosition)The ground's world height under a world position, taking the terrain object's position, rotation and scale into account
HeightAt(localX, localZ)Height above the object at a local position. Outside the terrain, the edge's height.
NormalAt(localX, localZ)The ground's up direction there
LayerAt(localX, localZ)The most strongly painted layer there, or −1 for none. Good for footstep sounds.
Sculpt(brush, localX, localZ, radius, strength, level, layer)Applies a brush. Strength is in local units for Raise and Lower and a 0–1 blend for the others; scale it by Time.deltaTime for a steady effect.
Generate(seed, featureSize, octaves, roughness, amount)Fills with hills, as in the Inspector
Flatten(level), SmoothAll(passes)Makes it all one height, or evens it out
GetHeight01(x, z), SetHeight01(x, z, value)Read or set one grid point, 0 to 1 of Height
AddLayer, SetLayer, RemoveLayer, FillLayer, ClearPaint, LayersManage paint layers
Resize(resolution)Changes the number of grid points, keeping the shape

Terrain is saved in the scene file in compressed form, so even large terrains keep scene files reasonably small.
