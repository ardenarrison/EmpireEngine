Using the editor

The AI assistant (optional)

A chat inside the editor that can help you write and fix scripts. It uses the Claude API from Anthropic with your own API key. It is off until you agree to a notice, it sends nothing until you press Send, and it never changes your project by itself.

Turning it on

  1. Open Help > AI Assistant…. The first time, it shows a notice about what is sent, where it goes, and who pays. Read it, tick I agree and press Turn on the assistant. Nothing is switched on before that.
  2. Enter your Anthropic API key. Create one in the Anthropic Console (the Get a key button opens it). You need an Anthropic account with credit.
  3. Type a question and press Send (or Return).

What you can do

  • Ask anything about your game, a script, or how Empire Engine works. The assistant knows the basics of Empire Engine scripting and says so when it isn't sure something exists.
  • Attach the open script. When a script is open in the code view, tick Send it under Open script to include its text with your question.
  • Attach the selected object. Tick Send it under Selected object to include its name, position, scale and the names of its components and scripts.
  • Copy answers. Each answer has Copy answer and, if it holds code, Copy code buttons. You paste what you want into your scripts. The assistant never edits files itself.
  • Choose a model under Settings. Larger models answer better and cost more per question.
  • Stop cancels a question that is still waiting. Clear empties the conversation.

The editor's text font only has plain letters, so characters it can't draw (emoji, accents) show as ? in the chat. Copying an answer copies the real text.

What is sent, and where

  • Only when you press Send, and only to api.anthropic.com over https. The editor refuses to send the key anywhere else.
  • What goes: your question, the earlier messages of this conversation (the last 20), a short fixed instruction describing Empire Engine scripting, and whatever you ticked. Nothing is attached unless you tick it, and the ticks are remembered but start off.
  • A script's name is sent, never its file path, so folder and user names stay on your computer. Attachments over 40,000 characters are cut, and the message says so.
  • What doesn't go: other scripts, scenes, models, your project folder, or anything you didn't tick or type.
  • Anthropic's terms and privacy policy apply to what you send. If your project is confidential, read them first. The notice has buttons for the Usage Policy, the Privacy Policy and the Commercial Terms.
  • Empire Engine has no server in the middle and receives nothing.

Your API key

  • Empire Engine has no key of its own. You bring yours, and Anthropic bills your account for each question. Each answer shows how many tokens it used.
  • Where it is kept: in one file in your user folder (EmpireEngineEditor/anthropic-api-key inside the app-data folder: ~/Library/Application Support on macOS, ~/.config on Linux, AppData on Windows). On macOS and Linux the file can be read only by you. It is not encrypted, so on a shared computer use the next option.
  • Or an environment variable: set ANTHROPIC_API_KEY and the editor uses that and saves nothing. It takes priority over a saved key.
  • The key is never put in a project, a scene, a log or the editor's error reports, and it is removed from any error text before it is shown. Settings > Remove saved key deletes the file.
  • The settings (whether you agreed, the model, what you chose to attach) are in assistant.json next to it. The conversation itself is kept in memory only and is gone when you close the editor.
  • Don't share your key, and don't commit it to a repository. If it leaks, delete it in the Anthropic Console.

The assistant can't use a Claude.ai subscription (Free, Pro or Max): those logins are for Anthropic's own apps. It needs an API key.

Please keep in mind

  • Answers can be wrong or unsafe. Read code before you run it, and test it.
  • Follow Anthropic's Usage Policy in what you ask.
  • Don't send secrets such as passwords or keys, or other people's personal data.
  • If a script contains instructions, they are treated as part of your project, not as orders to the assistant, but no assistant is perfectly resistant to that. Don't attach scripts from sources you don't trust.

If something goes wrong

You seeWhat it means
Anthropic rejected the API keyThe key is wrong, deleted or expired. Enter a new one under Settings.
…usage limit… or credit balance too lowYour account is out of credit or over a limit. Add credit in the Anthropic Console.
Anthropic doesn't know that model namePick another model in Settings.
Anthropic's service is busyTry again in a moment.
Couldn't reach AnthropicCheck your internet connection.

A question that got no answer is taken back, so the conversation stays in step.

Turning it off

Settings > Turn off the assistant switches it off and clears the conversation; the notice is shown again if you turn it back on. Removing the saved key stops it from sending anything. Games you build never contain the assistant: it is part of the editor only.

For people changing the editor

  • The code is in Editor/Assistant/: AssistantClient (the API calls), AssistantSettings (settings and the key store), AssistantPrompt (what is sent) and AssistantWindow (the window). The first three are plain .NET and are tested in Tests/.
  • Keep it bring-your-own-key. Never add a key to the code, a build or a config file, and don't send to any address other than api.anthropic.com. Tools/check_repo.py fails if something that looks like an Anthropic key is committed.
  • If you change what is sent or stored, update the notice in AssistantWindow and raise AssistantSettings.CurrentConsentVersion so everyone is asked again.
