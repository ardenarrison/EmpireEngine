Animation

An Animator plays animation clips from glTF files on its object's model. Give each clip an id, then play it from a script with animator.Play("Walk").

Setting up an Animator

  1. Have an object with a Mesh showing an animated .glb or .gltf model. (The Animator moves its own object's model or, failing that, the first model on an object under it.)
  2. Add an Animator component and press Add Animation for each clip you want.
  3. In the Assets panel, click the small arrow on a model file to list its animations, and drag one onto an entry's Clip field. The entry's id becomes the clip's name; change it to something short like Walk.
  4. Press Preview on an entry to watch it in the editor without playing the game.

Speed (all) on the Animator multiplies the speed of everything it plays.

Sharing animations between characters

A clip can come from a different file than the model, as long as the two use the same bone names. Keep one file of animations and use it on every character rigged the same way.

From scripts

public class Walker : Behaviour
{
    public float speed = 3f;

    public override void Update()
    {
        bool moving = Input.GetAxis("Vertical") != 0;
        Translate(0, 0, -Input.GetAxis("Vertical") * speed * Time.deltaTime);

        if (moving && !animator.IsPlaying("Walk"))
            animator.Play("Walk", fadeSeconds: 0.2f);    // blend in instead of cutting
        else if (!moving && !animator.IsPlaying("Idle"))
            animator.Play("Idle", 0.2f);
    }
}
MemberDoes
Play(id, fadeSeconds = 0)Starts the animation from its beginning. With a fade above 0 it blends in from the current pose over that time, which looks better when switching from walking to running.
Stop()Stops everything and puts the model back in its resting pose
Stop(id)Stops that animation, if it's the one playing
Pause(), Resume()Freezes and continues
IsPlaying(), IsPlaying(id)Whether anything (or that one) is playing. A finished, non-looping animation isn't.
IsPausedWhether it's paused
CurrentIdThe id playing now, or ""
Time, DurationSeconds into the current animation (settable, to jump) and its length
Has(id)Whether an animation with that id has been added
SpeedMultiplies the speed of everything it plays

Animators follow Time.timeScale.

What's supported

  • Skinned characters (meshes with joint weights) and node animation (moving parts of a model)
  • Clips from .glb and .gltf only. FBX and OBJ animations are not read; export animated models as glTF.
  • Not yet: morph targets (blend shapes).

If a clip can't be matched to the model's skeleton, the Animator prints one message to the console and skips it. When you re-export a model, clips that use it are matched again automatically.
