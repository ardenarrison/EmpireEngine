Systems

Audio

An Audio Source plays an MP3 or WAV file from the project, either flat (2D, for music and menus) or from its object's position in the world (3D).

Playing a sound

  1. Put an .mp3 or .wav file in the project, for example Audio/Theme.mp3.
  2. Drag it from the Assets panel onto the scene. That makes an object with an Audio Source that plays it. Or add an Audio Source component and drop the file on its Clip field.
  3. Press Play. With Play On Awake on (the default), it starts with the scene.

In edit mode the Audio Source's Play and Stop buttons let you listen to the clip.

Audio Source settings

These are the same settings as Unity's Audio Source.

SettingDefaultMeaning
ClipThe sound file, relative to the project folder
MuteoffSilences it but keeps it playing
Play On AwakeonStarts when the scene starts playing
LoopoffStarts over at the end
Priority1280 is most important, 256 least. Matters when too many sounds play at once.
Volume10 to 1
Pitch1Playback speed, −3 to 3. A negative pitch plays backwards.
Stereo Pan0−1 all left, 1 all right, for 2D sound
Spatial Blend00 is a 2D sound; 1 is a 3D sound heard from the object's position

3D sound

These matter as Spatial Blend rises above 0.

SettingDefaultMeaning
Doppler Level1How much moving sounds change pitch. 0 turns it off; 5 exaggerates it.
Spread00 to 360. Widens the sound so it pans less; 180 and up is centered.
Rolloff ModeLogarithmicLogarithmic: full volume inside Min Distance, then falls as 1 / distance, like real sound. Linear: falls in a straight line from full at Min Distance to silent at Max Distance.
Min Distance1Closer than this, the sound is at full volume
Max Distance500Where the sound stops getting quieter

The listener

3D sounds are placed relative to the Audio Listener's position and facing. Put one on your camera. A scene without one is heard from its first camera.

AudioListener.Volume = 0.5f;   // master volume for everything, 0 to 1
AudioListener.Pause = true;    // stop all sound where it is; false carries on

From scripts

audioSource.Play();               // from the start (or the end, with a negative pitch)
audioSource.PlayDelayed(0.5f);    // after a wait
audioSource.Pause();
audioSource.UnPause();
audioSource.Stop();

audioSource.PlayOneShot("Audio/Step.wav", 0.8f);   // on top of whatever is playing; good for overlapping effects
AudioSource.PlayClipAtPoint("Audio/Boom.wav", hitPoint);   // from a point in the world, no object needed

bool playing = audioSource.IsPlaying;   // also true during a PlayDelayed wait
audioSource.Time = 30f;                 // jump to 30 seconds in
float length = audioSource.ClipLength;

Notes

  • Sound files are decoded once into memory, so playing them never touches the disk. A clip with more than two channels keeps only the first two.
  • Save games remember where each Audio Source was in its clip and carry on from there.
  • If the computer has no sound device, the editor runs silently instead of failing.
