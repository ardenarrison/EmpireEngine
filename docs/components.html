Reference

Component reference

Every built-in component, its class name for scripts, its settings and their defaults. Each section links to the page that explains it in depth.

Component names in Add Component are on the left of each heading; the C# class is in brackets. Settings are properties on the class with the same name (without spaces): Use Gravity is UseGravity.

Mesh (MeshRenderer)

Draws a model. Models →

SettingTypeDefaultMeaning
Modelstringfirst model in Models/Path from the project folder
TintVector4(1, 1, 1, 1)Multiplies the model's color

Runtime only (not saved): Mesh, a model built by a script and drawn instead of Model; Pose, the current animated pose.

Script (ScriptComponent)

Attaches a Behaviour or a custom component. ScriptName is the class name; Fields holds the Inspector values as JSON text by field name. While playing, Instance is the running Behaviour, or ComponentInstance the custom component.

Audio Listener (AudioListener)

Where the scene is heard from; put it on the camera. One per object. No settings. Static AudioListener.Volume (master, 0 to 1) and AudioListener.Pause.

Spin (Spin)

Turns the object around the world Y axis while playing, with no script. Speed is in radians per second (default 1). Follows Time.timeScale.
