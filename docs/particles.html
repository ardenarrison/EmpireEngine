Systems

Particle systems

Fire, smoke, sparks and magic: a Particle System emits small camera-facing sprites and moves them over their lives. Its settings are grouped into modules, laid out like Unity's.

Adding one

Right-click in the Hierarchy and choose Particle System, or one of the presets below it. A particle system works on an empty object, and particle systems preview in the editor while you change their settings. The Inspector's Play/Pause, Restart and Stop buttons control the preview. The emitter's shape is drawn in orange on the selected object.

Presets

PresetLook
FireA steady flame: bright, additive and always burning
ExplosionA one-time fireball that bursts outward, slows quickly and fades. Press Restart to set it off again.
EmbersTiny glowing sparks that drift up and away, cooling as they go
SmokeSoft gray puffs that rise slowly, swell and fade

A preset sets every module; everything can still be changed afterwards. Sizes and speeds are for an object at scale 1, so scale the object to make the effect bigger.

Emission

Rate Over Time (10) is particles per second. Bursts emit Count particles at once, Time seconds into each cycle, repeated Cycles times Interval seconds apart.

Shape

Where particles start and which way they go. Every shape points along the object's +Y axis.

SettingMeaning
ShapeCone (default), Sphere, Hemisphere, Box, Circle or Point

Over lifetime

ModuleDoes
Velocity over LifetimeAdds a constant Linear velocity, such as wind
Limit Velocity over LifetimeDrag slows particles each second; Speed Limit caps their speed (0 for none)
Color over LifetimeMultiplies each particle's color by a blend from Start Color to End Color. By default it fades out.
Size over LifetimeMultiplies each particle's size by a blend from Start Size to End Size
Rotation over LifetimeSpins particles at an Angular Velocity in degrees per second
CollisionParticles bounce off flat ground at a world Ground Height. Bounce is the share of speed kept, Dampen the share of sliding speed lost, Lifetime Loss the share of life used up on each hit.

Renderer

  • Blend: Alpha (normal) or Additive, which brightens what's behind. Additive suits fire, sparks and magic.
  • Sprite: Soft Circle (default), Circle or Square.
  • Sort By Distance (on): alpha particles draw back to front so they overlap correctly.

From scripts

var sparks = GetComponent<ParticleSystem>()!;

sparks.Emit(30);          // 30 particles right now, playing or not
sparks.Play();
sparks.Stop();            // stop emitting; live particles finish their lives
sparks.Stop(clear: true); // and remove them
sparks.Pause();
sparks.Clear();
sparks.Restart();

sparks.Main.StartColor = new Vector4(1, 0.4f, 0.1f, 1);
sparks.Emission.RateOverTime = 50;

bool busy = sparks.IsPlaying;     // emitting, or any particle still alive
int alive = sparks.ParticleCount;

Particle systems follow Time.timeScale. Play mode starts every system fresh, so Play On Awake applies again each time.
