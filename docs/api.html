Reference

Scripting API reference

The classes scripts use most, with every public member. All are in Engine.Core.Scripting or Engine.Core.Scene, which scripts import automatically. Vectors and quaternions are System.Numerics types.

Reaching another script

Behaviours aren't components, so GetComponent can't find them. Go through the object's Script components:

var mover = other.Components.OfType<ScriptComponent>()
    .Select(s => s.Instance).OfType<Mover>().FirstOrDefault();

Or write the shared part as a custom component, which GetComponent does find.
