Physics

Give an object a collider and things bump into it. Add a Rigidbody too and it falls, slides, bounces and can be pushed.

Bodies and colliders

  • An object with a collider and no Rigidbody is static. It never moves under physics: ground, walls, level geometry.
  • An object with a Rigidbody is a body. Its colliders, and the colliders of children that have no Rigidbody of their own, are its shapes. Put several colliders on children to build a compound shape.
  • A kinematic Rigidbody (IsKinematic) is moved only by your scripts. It pushes other bodies but is never pushed.

Physics rebuilds its bodies from the scene on every step, so scripts may move objects or add and remove components at any time.

Collider shapes

ColliderShape
Box ColliderA box of Size around Center, both in the object's own space. Scales and turns with the object.
Sphere ColliderA ball of Radius around Center. Scales with the object's largest scale axis.
Mesh ColliderA model's shape. Leave Model empty to use the object's Mesh, or pick a simpler model (Choose collision model) for speed.
TerrainThe terrain's ground. Turn Collide off to make it scenery only.

A new Box or Sphere Collider is fitted to the object's model when it has one. In the editor, colliders are drawn as green outlines, brighter on the selected object.

Mesh colliders

On a static object or a kinematic body, a mesh collider uses the model's exact triangles, which is right for ground, ramps and buildings. On a moving body it uses the mesh's convex hull, the shape a shrink-wrap would make, so hollows and dents are filled in. Big meshes are simplified first so collision stays fast. The editor draws the hull a moving mesh collider uses.

Surface settings

Every collider has Friction (0 is ice, 1 is rubber, up to 2; default 0.5) and Bounciness (0 stops dead, 1 bounces back at full speed; default 0). When two colliders touch, their frictions are multiplied and square-rooted, and the bouncier of the two wins.

From scripts you can also read and set Velocity (units per second, world space) and AngularVelocity (radians per second). They aren't saved with the scene, but they are kept in save games.

Forces

rigidbody.AddForce(0, 0, -20);                                  // a steady push: call every frame
rigidbody.AddForce(new Vector3(0, 5, 0), ForceMode.Impulse);    // a jump
rigidbody.AddTorque(0, 2, 0);                                   // spin around Y
rigidbody.Velocity = Vector3.Zero;                              // stop dead
ForceModeMeaningMass matters?
Force (default)A push over time, in newtons. Call it every frame for a steady push.Yes
AccelerationA push over timeNo
ImpulseAn instant kick, like a jump or a hit. Same as AddImpulse(v).Yes
VelocityChangeAn instant change of speedNo
No Time.deltaTime with Force

Force and Acceleration are multiplied by the frame's length when you add them, so a push called every frame from Update is equally strong at any frame rate. Don't multiply by Time.deltaTime yourself. Forces are applied at the start of the next physics step.

Stepping

Physics runs at a fixed 60 steps per second, however fast frames come, and at most 5 steps per frame so one slow frame can't snowball. Contacts are solved with sequential impulses and remember last step's results, so stacks settle instead of jittering. Physics steps on real time and isn't slowed by Time.timeScale.

Gravity

Each scene has its own gravity, (0, −9.81, 0) by default, set in the scene settings. Scripts can change it:

Physics.Gravity = new Vector3(0, -1.6f, 0);   // the moon

Collision events

public override void OnCollisionEnter(SceneObject other) { ... }   // started touching
public override void OnCollisionExit(SceneObject other)  { ... }   // stopped touching

Both objects' scripts are told. Events fire after each physics step, so it's safe to remove objects or load scenes from them.

Raycasts

var forward = Vector3.Transform(-Vector3.UnitZ, Object.Rotation);

if (Physics.Raycast(Object.Position, forward, out var hit, 20f, ignore: Object))
    Console.WriteLine($"{hit.Object.Name} is {hit.Distance:0.0} m ahead");

bool blocked = Physics.Raycast(Object.Position, forward, 2f, ignore: Object);

foreach (var h in Physics.RaycastAll(Object.Position, forward, 50f))
    Console.WriteLine(h.Object.Name);   // every hit, nearest first

if (Physics.Raycast(Input.GetMouseRay(), out var under))   // what the mouse is over
    Console.WriteLine(under.Point);
RaycastHitMeaning
ObjectThe object hit
ColliderThe collider hit
PointWhere the ray touched, in the world
NormalThe surface's direction there
DistanceHow far along the ray
  • The direction doesn't need to be normalized. maxDistance defaults to infinity.
  • ignore skips an object and everything under it, which keeps a shooter from hitting itself.
  • As in Unity, a ray that starts inside a box or sphere doesn't hit it.
  • Mesh colliders are tested against their real triangles from both sides, even on moving bodies that collide as a hull.
