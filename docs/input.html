Scripting

Input and time

Read the keyboard and mouse with Input, and make movement smooth at any frame rate with Time.

Keyboard

if (Input.GetKey(Keys.W))        { /* every frame W is held */ }
if (Input.GetKeyDown(Keys.Space)) { /* only the frame Space went down */ }
if (Input.GetKeyUp(Keys.E))       { /* only the frame E came up */ }

// The same with key names, as visual scripts use them:
if (Input.GetKey("Shift")) { ... }

Name strings ignore capital letters. An unknown name throws an error, which stops the script with a message saying which name was wrong.

Axes

Input.GetAxis gives a value for the common controls, as in Unity:

AxisValue
"Horizontal"−1 to 1 from A/D or ←/→
"Vertical"−1 to 1 from S/W or ↓/↑
"Mouse X"Mouse movement to the right this frame
"Mouse Y"Mouse movement upward this frame
"Mouse ScrollWheel"The scroll wheel this frame

The keyboard axes jump straight to −1, 0 or 1 (there's no smoothing). The mouse axes are a tenth of the movement in screen points, so multiply by a sensitivity that feels right.

Mouse

if (Input.GetMouseButtonDown(MouseButton.Left)) { ... }   // also 0, 1, 2 or "Left", "Right", "Middle"
bool aiming = Input.GetMouseButton(1);                     // right button held

Vector2 p = Input.mousePosition;     // in the game view, from its top-left corner, y down
Vector2 d = Input.mouseDelta;        // movement since last frame
float wheel = Input.mouseScrollDelta;  // up is positive
Vector2 size = Input.screenSize;     // the game view's size, in the same units

Mouse-look

Set Input.cursorLocked = true to hide the cursor and hold it in the window. mouseDelta (and the mouse axes) keep reporting movement. In the editor, Esc or stopping the game frees it again.

public class MouseLook : Behaviour
{
    public float sensitivity = 2f;
    private float _yaw, _pitch;

    public override void Start() => Input.cursorLocked = true;

    public override void Update()
    {
        _yaw   -= Input.GetAxis("Mouse X") * sensitivity;
        _pitch += Input.GetAxis("Mouse Y") * sensitivity;
        _pitch = Math.Clamp(_pitch, -85f, 85f);
        Object.Rotation = Quaternion.CreateFromYawPitchRoll(_yaw * MathF.PI / 180f, _pitch * MathF.PI / 180f, 0);
    }
}

Set Input.cursorVisible = false to hide the cursor over the game but leave it free to move.

What's under the mouse

if (Input.GetMouseButtonDown(0) && Physics.Raycast(Input.GetMouseRay(), out var hit))
    Console.WriteLine($"Clicked {hit.Object.Name} at {hit.Point}");

Input.GetMouseRay() is the ray from the camera through the mouse. Input.ScreenPointToRay(point) does the same for any point in the game view.

Time

FieldMeaning
Time.deltaTimeSeconds since the last frame, multiplied by timeScale. Multiply speeds by it.
Time.unscaledDeltaTimeThe same, not affected by timeScale. Use it for menus while the game is paused.
Time.timeScale1 is normal. 0 freezes the game, 0.5 runs it at half speed, 2 at double. Animation, particles and coroutine waits follow it. Physics does not: it steps on real time (see below).
Time.timeScaled seconds since play started. Saved with save games.
Time.fpsFrames per second, smoothed so it reads steadily. 0 before the first frame.
 
// 5 units per second, however fast the game runs:
Translate(0, 0, -5f * Time.deltaTime);

// Pause and resume:
if (Input.GetKeyDown(Keys.Escape)) Time.timeScale = Time.timeScale == 0 ? 1 : 0;
timeScale and physics

The physics simulation is stepped with the real frame time, so Time.timeScale = 0 does not freeze rigidbodies: they keep falling and sliding. Forces from AddForce are scaled by Time.deltaTime, so they do stop. To pause physics, set the rigidbodies to IsKinematic while paused.

Escape in the editor

While you play in the editor, Esc stops play mode, so a pause menu bound to Escape can only be tried in a built game. Use another key such as P or Tab while testing.
